驗收條件

我們會從同一個 TEST GitHub 儲存庫讀取歷史基準，將候選文字中原有的擁有者識別碼代入基準，再加上指定任務、公開暱稱與私人推播訂閱的三組規則。只有完整文字逐字相同，才會顯示 PASS。

若顯示 HOLD，就不要發布。即使顯示 PASS，仍須確認 Firebase 畫面使用的專案是 honbin-crm-notes-spark、不是正式 CRM；Firebase 編輯器在正式發布時仍會執行自己的規則編譯檢查。
