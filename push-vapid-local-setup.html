iPhone 推播金鑰｜手機本機產生

只供 CRM 系統管理者使用。這個頁面不連接 Firebase、GitHub API 或其他伺服器，不會上傳或儲存產生的金鑰。關閉頁面後金鑰會從頁面消失；請先將成對金鑰分別安全存入 GitHub Actions Secrets。

1．產生 Web Push VAPID 金鑰

使用 iPhone 瀏覽器內建 Web Crypto P-256 金鑰生成；不需付費、下載程式或註冊新帳號。

尚未產生；正式系統推播仍關閉。

公開金鑰（可公開）

將它存入雲端記事 GitHub 儲存庫的 Actions Secret：TEST_VAPID_PUBLIC_KEY。待所有安全測試 PASS，正式 CRM 的公開設定才會使用這個值。

私人金鑰（保密）

只能存入 GitHub 儲存庫加密的 Actions Secret TEST_VAPID_PRIVATE_KEY。不要貼到聊天室、程式碼、GitHub Issue、一般文字檔或任何雲端共用文件。

2．其他免費、安全設定

在同一 GitHub 儲存庫 Actions Secrets 另外設定 TEST_PUSH_CONTACT，值以 mailto: 開頭並使用你可收信的地址。Firebase 專用服務帳號憑證若已設定，請沿用，不要另建管理員萬用金鑰。

現有系統在完成權限核對、兩個帳號隔離驗證與兩支 iPhone 實測之前，不得將 TEST_PUSH_SEND_ENABLED 設為 EXPLICITLY_APPROVED。本頁不會開啟任何推播。
